# LEX Auto Publisher Pro

بوت تيليجرام (Telethon، بوت token) ينشر تلقائياً كل رسالة نصية تتبعث في مجموعة
مخصصة (Source) إلى 5 مجموعات مستهدفة (Targets)، ويزامن التعديل والحذف عبر
قاعدة بيانات SQLite.

## المزايا
- نشر تلقائي (Text only) من المجموعة المصدر إلى كل المجموعات المستهدفة
- مزامنة التعديل (Edit sync)
- مزامنة الحذف (Delete sync) — **شوف التنبيه تحت**
- أمر `/status` و `/id` (مخصصين لصاحب البوت فقط عبر `OWNER_ID`)
- إعادة محاولة تلقائية عند FloodWait أو أخطاء RPC

## ⚠️ تنبيه مهم حول اكتشاف الحذف مع Bot Token

هذا الإصدار يسجل دخول كـ **بوت** (`bot_token`) وليس كحساب مستخدم. تيليجرام
لا يبعث دائماً حدث حذف الرسائل (`MessageDeleted`) للبوتات في المجموعات —
هذا سلوك متعلق بالـ Bot API نفسه وليس خطأ في الكود. جرّب الميزة فعلياً بعد
النشر:

- إذا خدمت مزامنة الحذف مباشرة → تمام، كمّل بيها.
- إذا لاحظت أن الحذف ما يتزامنش، الحل الموثوق هو استعمال **حساب مستخدم**
  (تسجيل بـ `client.start(phone=...)` بدل `bot_token`) بدل بوت — هذا محتاج
  رقم هاتف الحساب المستعمل، ولازم يكون عضو/أدمين في كل المجموعات.

## التنصيب

```bash
git clone <رابط_المستودع_تاعك>
cd lex-auto-publisher
pip install -r requirements.txt
cp .env.example .env
```

عدّل `.env` وحط فيه:
- `API_ID` / `API_HASH`: من https://my.telegram.org
- `BOT_TOKEN`: من [@BotFather](https://t.me/BotFather)
- `OWNER_ID`: الـ user id تاعك
- `SOURCE_CHAT_ID`: معرف مجموعة النشر المخصصة
- `TARGET_CHAT_IDS`: معرفات المجموعات المستهدفة مفصولة بفاصلة

**البوت لازم يكون عضو/أدمين في المجموعة المصدر وفي كل المجموعات المستهدفة**
باش يقدر يقرا وينشر ويحذف.

## التشغيل

```bash
python lex_publisher.py
```

## أمان

- لا ترفع أبداً `.env` أو `*.session` أو `lex_publisher.db` لـ GitHub —
  `.gitignore` مضبوط يستثنيهم تلقائياً، تأكد بلي ما زدتهمش بالغلط.
- `BOT_TOKEN` يعطي وصول كامل للتحكم بالبوت — تعامل معاه كإيميل/باسورد.
